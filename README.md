# Dhruv Jain — Portfolio Website

A modern, animated personal portfolio website built with Next.js, showcasing my projects, skills, work experience, and achievements as a Full Stack Developer.

## 🚀 Live Preview

> Coming soon — will be deployed on Vercel.

## ✨ Features

- **Animated Preloader** — Smooth GSAP-powered intro animation
- **Interactive Hero Section** — Bold typography with profile image and social links
- **Projects Showcase** — Featured projects with tech stacks, descriptions, and GitHub/demo links
- **Work Experience** — Timeline-style experience cards with bullet points
- **Skills & About** — Categorized skills (Languages, Frontend & Backend, AI & ML)
- **Achievements & Certifications** — LeetCode, Kode Kombat, CCNA, AWS, and more
- **Contact Section** — Email link and social media connections
- **Smooth Animations** — Framer Motion scroll-triggered animations throughout
- **Responsive Design** — Fully responsive across all device sizes
- **Custom Cursor** — Interactive blob cursor effect with Blobity

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| **Framework** | Next.js 13 (App Router) |
| **Language** | TypeScript, React |
| **Styling** | Tailwind CSS |
| **Animations** | Framer Motion, GSAP |
| **Icons** | Font Awesome |
| **Cursor** | Blobity |
| **Hosting** | Vercel |

## 🏃 Run Locally

Clone the project

```bash
git clone https://github.com/dHrUV0121/Portfolio_Dhruv.git
```

Go to the project directory

```bash
cd Portfolio_Dhruv
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
